Data sources & licenses

The default sources need no paid account or API key for personal, noncommercial use. Detail varies by location and survey date. A finer mesh or a higher tile zoom cannot add features missing from the original survey or photograph.

Slow or missing data retains the available terrain and imagery. Fallback elevation retries the preferred source while remaining visible. PNG exports add no further JPEG compression; elevation is transferred as floating-point heights without compression error. These export formats do not recover detail already lost in the original data.

There is no single globally finest free source. Local public surveys can exceed these general services, and high-resolution coverage is not universal. The app does not claim that every location has 1 m elevation or sub-metre imagery.

Imported routes

Outside the supported US elevation regions, terrain uses the global Mapzen fallback. Outside the conterminous US, the complete imagery overview uses the approximately 10 m EOxCloudless mosaic, capped at Z15. Swiss imports can additionally load fine SWISSIMAGE photography at Z16–Z19. Nepal and New Zealand currently retain the global imagery fallback; importing a detailed GPX does not supply matching high-resolution terrain.

Swiss eligibility uses the service's rectangular envelope, not a country or survey-coverage polygon. Every pixel of a fine PNG must be opaque before publication. Border/missing coverage retains the complete overview; the viewer never enlarges it under a fine tile label. The source's native 10–25 cm pixels are distinct from actual Web Mercator tile sampling (about 0.21 m at Z19 in this region). Finest 10 cm source detail is not fully resolved by Z19. Further regional imagery/elevation upgrades remain open.

Optional providers

Free API-key services are eligible for this personal/internal viewer when their terms, usage limits and account plan keep use free. An API key does not imply a paid license. Fine public regional data remains preferable to a coarser keyed service; compare native detail and coverage for the location.

  • LINZ Basemaps: no-charge standard and developer imagery API access for New Zealand. Standard keys renew after 90 days. Attribution is required. Not integrated yet.
  • MapTiler Cloud Free: currently no card required, 100,000 API requests per month, personal/noncommercial use and required branding. The Free plan suspends at its limit; paid plans can charge overages. Terms allow temporary individual-device caching, not bulk downloads or proxying without agreement. Not integrated yet.
  • OpenTopography: free non-academic global DEM keys currently permit 50 calls per day, with private, unshared keys. Its USGS 1 m raster API requires academic eligibility. Suitable candidates for private/local terrain preparation; not a public embedded key. Not integrated yet.

Esri World Imagery and Bing via Cesium Ion can be selected directly in the Settings panel under Satellite & Aerial Source. Esri World Imagery provides high-resolution worldwide Maxar/NAIP imagery at no charge for personal viewing with attribution. Bing Aerial requires an optional Cesium Ion Community token.

Device caching

The viewer saves original encoded imagery and validated USGS elevation files on this device when the reviewed source permits reuse. The cache holds up to 256 MiB or 4,096 resources, expires entries after seven days, and removes the least recently used data to stay within its limits. Settings lets you pause reuse/saving or clear saved terrain and imagery. Unkeyed Esri World Imagery and public services participate in this persistent cache.

Cached files are not recompressed or reduced in precision. Disk storage is separate from decoded image and GPU budgets. Storage can be unavailable or reclaimed by the browser; the app continues with network loading. This is revisited-data caching, not an offline app or a complete downloaded route. Preferred-source ordering is preserved, so an uncached preferred service can still need probing before a cached alternative is used.

Before reusing Swiss imagery from device storage, the viewer checks the official mosaic cache revision once per page. A changed revision makes older stored Swiss imagery ineligible. If the revision check fails, Swiss imagery continues over the network while persistent Swiss reuse/saving is skipped for that page.
